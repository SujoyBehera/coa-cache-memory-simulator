Demonstrate fundamental Computer Organization principles to your professors during your project demonstration. Click any experiment below to configure the simulator and execute the test sequence automatically!

EXPERIMENT 1
Direct Mapping Thrashing & Ping-Pong Conflicts
In Direct Mapping, multiple distinct memory blocks map to the exact same set index. In this experiment, Block 0 (Addr 0) and Block 16 (Addr 64) both map to Set Index 0. Alternating between them causes a 100% Conflict Miss rate (Thrashing), despite 15 empty cache lines!
• Trace: 0, 64, 0, 64, 0, 64, 0, 64 (Addresses map to Set 0)
• Direct Mapped Result: 0% Hit Rate (Catastrophic thrashing)
• 2-Way Associative Fix: Both fit in Set 0 (75% Hit Rate)
EXPERIMENT 2
Replacement Policy Showdown: FIFO vs. LRU
FIFO evicts the line that entered the cache earliest, ignoring repeated recent access. LRU preserves frequently re-accessed blocks. This experiment runs a cyclic working set that causes FIFO to evict an actively used block while LRU retains it, yielding a higher hit rate.
• Trace: 0, 4, 8, 12, 0, 16, 0, 4, 8
• Cache: 16-Byte Cache, 4-Byte Blocks, 2-Way Set Associative
• Observe how LRU timestamp updates prevent premature eviction of Block 0.
EXPERIMENT 3
Spatial Locality & Block Size Scaling
When consecutive memory bytes are accessed (e.g. iterating an array), a larger block size fetches neighboring bytes into the cache on the first miss. This experiment tests sequential accesses (0, 1, 2, 3, 4, 5, 6, 7) and shows how 4-byte and 8-byte blocks slash compulsory misses.
• 2-Byte Blocks: 4 Misses / 8 Accesses (50% Hit Rate)
• 4-Byte Blocks: 2 Misses / 8 Accesses (75% Hit Rate)
• 8-Byte Blocks: 1 Miss / 8 Accesses (87.5% Hit Rate)
EXPERIMENT 4
Write-Back (Dirty Bit) vs. Write-Through Bus Traffic
Examine how memory store operations are handled. Write-Through forwards every single write to the main memory bus. Write-Back sets a Dirty Bit (D=1) in the cache line and only incurs main memory bus traffic when a modified block is evicted from the cache.
• Trace: W:0, W:0, W:0, W:0, R:32 (Overwrites Addr 0, then evicts it)
• Write-Through Bus Writes: 4 writes to RAM
• Write-Back Bus Writes: Exactly 1 write to RAM upon eviction!
